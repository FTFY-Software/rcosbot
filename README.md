# rcosbot

Moderation and audit-logging bot for the AquaFPS Discord server.

Published documents, required for Discord's app verification:

- [Privacy Policy](https://ftfy-software.github.io/rcosbot/privacy)
- [Terms of Service](https://ftfy-software.github.io/rcosbot/terms)

Both are served by GitHub Pages from the `docs/` directory on `main`. Edit the Markdown there and
Pages rebuilds automatically; the commit history of this repo is the change record for both
documents.
