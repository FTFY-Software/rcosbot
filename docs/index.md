# rcosbot

rcosbot is the moderation and audit-logging bot for the AquaFPS Discord server. It enforces the
server rules automatically, keeps a staff-visible record of moderation actions, and answers the
`/privacy` command in Discord.

- [Privacy Policy](privacy)
- [Terms of Service](terms)

Questions about either document, or about data the bot holds on you, should go to the server
moderators in Discord.
